- IFI is a *ratio*; when both the positive-lag and negative-lag means are near zero it becomes numerically unstable, and the function returns exactly 0 when their sum is ≤ 0 (`lagged.py:49-51`), which slightly over-populates the zero bin.
- The existence and change families are BH-corrected within pair × configuration only, not across the 420 cells.

### Fig4D_gini_across_learning_temporal

**Shows.** Three panels sharing a y-axis, all from the 25 ms committed configuration restricted to the striatal triangle: the corrected **partner-dependent** Gini for area X, the same for area Y, and — for comparison — the **partner-invariant** Gini that was retracted. Grey lines are individual animal × pair cells across naive → intermediate → expert, blue is the cohort median, and each panel is annotated with the animal-level Wilcoxon p for the naive→expert change. **All three are flat:** partner-dependent X 0.340 → 0.354 → 0.366 (p = 0.73), partner-dependent Y 0.379 → 0.369 → 0.365 (p = 0.30), partner-invariant X 0.436 → 0.487 → 0.472 (p = 1.00), all with n = 9 animals. The planned de-sparsification claim is refuted, and it is refuted under the metric that can actually bear a communication interpretation.

**Methods.** Source: `Striatum project/tcca/figures/grid_gini.png` (svg+png), produced by `tcca/scripts/figs_epoch_grid.py:204` (`fig_gini`) from `tcca/results/epoch_metrics_b25.csv`. **The metric correction.** The originally exported `gini_x/y` is the Gini coefficient of the per-neuron L2 norm of the neuron-space canonical weights taken across **all** d = min(k_x, k_y) retained canonical dimensions (`subspace_window.py:244-248, 258`, `membership.gini` at `tcca/src/striatum_tcca/membership.py:104-117`). Because the L2 row-norm over the full retained set cancels the partner-determined orthogonal factor, that quantity is **partner-invariant** — a readout of the area's own loading geometry, not of its coupling to any particular partner. The sibling TomLearning project demonstrated this analytically and empirically (r = 0.981 across different partners) and retracted the metric on 2026-07-28; the striatum export inherited the same defect (`documents/FIGURE_PLAN_AUDIT.md:254-261`). The replacement, `gini_pearson_x/y`, is computed with **no CCA and no PCA**: each neuron's Pearson-correlation row against the *other* area's entire population is taken, and the neuron's coupling magnitude is the L2 norm of that row; the Gini of those magnitudes is partner-dependent by construction (`tcca/src/striatum_tcca/membership.py:138-177`, called at `subspace_window.py:253`). Both are computed on the same residualised, run-masked, Z-partialled window matrices fed to the pCCA, so the control removes the CCA weight machinery but not the shared residualisation or run-masking. Gini uses the N/(N−1) small-sample correction so areas with different unit counts are comparable (`membership.py:104-117`). Statistic: per (animal, pair) cell, the expert-minus-naive difference; per-animal medians across that animal's pairs; two-sided Wilcoxon signed-rank over the 9 animals (`figs_epoch_grid.py:222-227`). Cohort: 68 striatal-triangle cells, 9 animals, 25 ms bins, FS-excluded, partial CCA. Recomputed from the CSV for this caption, the per-animal median naive→expert deltas are −0.008 (gini_pearson_x), −0.048 (gini_pearson_y) and +0.012 (gini_x).

**Caveats.**
- **The partner-invariant panel is shown only as a comparison and must be labelled as retracted in the caption.** It is not a communication measure; its value would be almost unchanged if the partner area were swapped.
- **The cohort-median trace and the paired test can disagree in sign.** For `gini_pearson_x` the median rises 0.340 → 0.366 while the per-animal median delta is *negative* (−0.008): the cross-sectional median is not the paired contrast. Quote the paired statistic, not the trace.
- **The Gini is an in-sample readout.** Unlike the held-out CC1, the canonical weights (and hence `gini_x/y`) come from a single full-window CCA fit, not the CV folds (`subspace_window.py:208-211, 244-248`). `gini_pearson` is CCA-free but is likewise computed on the full window.
- **The corrected metric's absolute level is not comparable across pairs.** The noise floor of an L2-norm Gini is set by the number of partner units, so only the within-animal *slope* across epochs is interpretable (`membership.py:151-156`).
- **The control is not orthogonal to the pipeline**: `gini_pearson` shares the residualisation, the running-bin mask and the third-area partialling with the CCA, so it rules out the weight machinery as an explanation but not the preprocessing.
- **Power**: n = 9 animals; the exact two-sided signed-rank floor is 0.0039, but with per-animal median shifts of 0.008–0.048 Gini units, only a large effect would have been detectable.
- **Canonical axes are refit per epoch.** The temporal arm does not freeze the canonical axes across epochs (`FIGURE_PLAN_AUDIT.md:262-266`), so an epoch contrast on any weight-derived quantity confounds genuine change with axis drift. This is harmless for a scalar strength null but is precisely the failure mode the sibling project hit twice on membership claims; the Gini panel is a membership-flavoured claim and inherits the concern. `gini_pearson`, being CCA-free, is immune to it — a further reason to lead with the corrected metric.
- No LP-shuffled null.

No statistic is computed for either panel.

The within-epoch split-half machinery exists in the codebase (`cca/src/striatum_cca/subspace.py:44-88`) and is used for the principal-angle panel, but **no split-half floor is computed for membership Jaccard** (`jaccard` is called only from `plot_stage3.py:181, 189`) — so there is no empirical noise floor against which the cross-epoch value of 0.206 can be judged.
